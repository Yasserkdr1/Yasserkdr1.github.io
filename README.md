# Yasserkdr1.github.io

Responsive cybersecurity portfolio built for GitHub Pages.

## Publish

1. Create a public repository named **`Yasserkdr1.github.io`**.
2. Upload everything in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select **`main`** and **`/(root)`**.
5. The site will be available at `https://yasserkdr1.github.io`.

## Structure

- `index.html` — portfolio content
- `css/styles.css` — desktop + responsive mobile styles
- `js/main.js` — architecture modal, reveal effects, sticky header behavior
- `assets/` — existing project visuals and architecture diagrams

The site uses no framework and no external dependency, so it is easy to maintain and fast on GitHub Pages.
